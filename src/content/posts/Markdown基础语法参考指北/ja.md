## 1. 見出しと階層（Headings）
`#`で見出しを表します。`#`の後に半角スペースを入れ、見出しを入力します。
# 第1レベルの見出し（H1）：`# 第1レベルの見出し`

## 第2レベルの見出し（H2）：`## 第2レベルの見出し`

### 第3レベルの見出し（H3）：`### 第3レベルの見出し`

---

## 2. テキストの書式（Emphasis）
* *斜体*  `*斜体のテキスト*` または `_斜体のテキスト_`

* **太字**  `**強調するテキスト**` または `__強調するテキスト__`

* ***太字の斜体***  `***太字かつ斜体***`
 
* ~~取り消し線~~  `~~誤りや古いテキスト~~`

* <u>下線</u>  `<u>HTMLタグで実現</u>`

* `背景色付きテキスト`  バッククォートでテキストを囲みます。例：`\`&emsp;\`テキスト\``。

* 空白文字
  
`&nbsp;`	行末で単語が分割されるのを防ぐ、よく使われる改行禁止スペースです。  
`&ensp;`	半角スペースで、幅はおよそ小文字nと同じです。  
`&emsp;`	全角スペースで、幅はおよそ小文字m（通常は全角1文字分）です。

## 3. リストと整理（Lists）

### 箇条書き（Unordered List）
* 自然言語処理（NLP） `* 自然言語処理（NLP）`

* 計算言語学（CL） `+ 計算言語学（CL）`

* 機械学習（ML） `- 機械学習（ML）`

### 番号付きリスト（Ordered List）
`1.`、`2.`、`3.`のように入力します：
1. 前処理（Preprocessing）    `1. 前処理`

2. 特徴抽出（Feature Extraction）    `2. 特徴抽出`

3. モデル学習（Model Training）    `3. モデル学習` 


### タスクリスト（Task Lists）
* [x] 形態素解析を完了 `* [x] 形態素解析を完了`  

+ [ ] Pythonスクリプトを書く `+ [ ] Python自動化スクリプトを書く`  

- [x] PDFにエクスポート `- [x] PDFにエクスポート`

## 4. 引用

### 通常の引用
`>`記号を使います。引用はネストできます：
```md
> 私の言語の限界は、私の世界の限界を意味する。
>> — ウィトゲンシュタイン
```
> 私の言語の限界は、私の世界の限界を意味する。
>> — ウィトゲンシュタイン    

### GitHub形式のコールアウト
```md
> [!caution]
> 私の言語の限界は、私の世界の限界を意味する。
>> — ウィトゲンシュタイン
```
> [!caution]
> 私の言語の限界は、私の世界の限界を意味する。 
>> — ウィトゲンシュタイン

または

```md
> [!caution/カスタム見出し]
> 私の言語の限界は、私の世界の限界を意味する。
>> — ウィトゲンシュタイン
```
> [!caution/カスタム見出し]
> 私の言語の限界は、私の世界の限界を意味する。 
>> — ウィトゲンシュタイン

### `:::`形式のコールアウト
```
:::tip
見出しなし  
xxxfoo
:::
```
:::tip
見出しなし  
xxxfoo
:::

```
:::tip[見出し]
見出しあり  
xxxfoo
:::
```
:::tip[見出し]
見出しあり  
xxxfoo
:::


:::caution[注意]
特殊なコールアウトを正しく表示するには、対応するパッケージを`pnpm install`でインストールしてください。
:::

## 5. 区切り線と表
### 水平線
```md
---（ハイフン3つ："-"）
または
***（アスタリスク3つ："*"）
または
___（アンダースコア3つ："_"）
```
表示例：

---

または

***

または
___


---
### ディレクトリツリー

Windows：Altキーを押しながらテンキーで次の数字を入力します  

Alt + 179 = │  

Alt + 196 = ─ 

Alt + 195 = ├    

Alt + 192 = └     

この4種類の線を使えば、複雑な`ディレクトリツリー`を作成できます。  
以下は3階層の`ディレクトリツリー`です：

```
blog-root
├── config
│   ├── database.js
│   ├── utils
│   └── helper.js
├── media
│   ├── musics
│   ├── images
│   └── videos
└── README.md
```

### 表
- 各列のテキストを` | `で区切ると表になります。表示時には縦棒は隠れます。
- 1行目と2行目には見出し行と区切り行が必要です。
- 区切り行に次の記号を使って、表内の文字を配置します：  
**左揃え**   `:---`  
**中央揃え**   `:---:`  
**右揃え**   `---:`  


```
| 左揃え | 中央揃え | 右揃え |
| :--- | :---: | ---: |
| Apple | Banana | またはange |
| ドラゴンフルーツ | スイカ | イチゴ |
```
| 左揃え | 中央揃え | 右揃え |
| :--- | :---: | ---: |
| りんご | バナナ | オレンジ |
| ドラゴンフルーツ | スイカ | イチゴ |

**中央揃えと右揃えは、このブログテーマの表の配置スタイルと競合します。他のMarkdownアプリで表示してください。*

## 7. 画像と動画

```

注：./落日余晖.jpgは、記事と同じフォルダーにある「落日余晖」という名前の.jpg画像を指します。
```

## 9. コードブロック（Code Blocks）

### インラインコード
1組のバッククォートで囲みます。例：\`import spacy\`。表示結果は`import spacy`です。
<br> 

### フェンス付きコードブロック（Code Fencing）
```` ``` ````の後にプログラミング言語を指定すると、構文がハイライトされます。例：

> \```python title="main.py  
\# 使用 Ginza/spaCy 包  
import spacy  
nlp = spacy.load("ja_ginza")  
print("正しくネストして改行されました")  
\```  
\### ここで最後です。これで終わりです！

コードブロックの末尾に```` ``` ````を入力して閉じます。全体の表示例：

```python title="main.py"
# Use the Ginza/spaCy package
import spacy
nlp = spacy.load("ja_ginza")
print("Successfully nested and wrapped")
```
### ここで最後です。これで終わりです！
